# かめはめ波・元気玉

iPhone などのブラウザーで遊ぶカメラゲームです。最大4人を認識し、各人に青・金・ピンク・緑のオーラを表示します。腰の横で両手を構えるとかめはめ波、頭上に両手を上げると元気玉をためます。手を前または左右へ押し出すと、その方向へ技を放ちます。

認識が途切れても、ためた気は粒になって周囲へ散ります。本人やほかの人が拾えます。拾われなかった粒は時間とともに消えます。

カメラ映像はブラウザー内だけで処理し、保存・送信しません。マイク権限も使いません。検出と音声の開始には、最初の画面でのタップが必要です。

## 開発

```sh
npm run build
npm test
python3 -m http.server 8000 --directory dist
```

ブラウザーで `http://localhost:8000` を開きます。`npm run build` は `src/` から `dist/` を作り、MediaPipe・Three.js・モデルを固定URLから取得して SHA-256 とサイズを検証します。ライセンス表示も `dist/vendor/` に含めます。

## 公開

`main` ブランチへの push で GitHub Actions がテストを実行し、GitHub Pages へ公開します。公開先は [GitHub Pages](https://mins-sr.github.io/Kamehameha/) です。iPhone Safari では HTTPS の URL を開き、カメラを許可してください。

## 確認

`npm test` はポーズ判定、チャージと発射、方向、誤発射防止、4人追跡、色の維持、気の散乱・回収・消滅、演出パラメーター、4人デモを合成データで確認します。実機カメラの認識、スピーカーからの音、ブラウザー上の描画は別途確認が必要です。
